# Alma & Aziz — Écrin turquoise 💎

Un écrin à bijoux en velours turquoise serti de strass et de perles.
On touche le bijou : il étincelle, le couvercle se lève sur un satin capitonné,
une fleur bijou (pétales turquoise et nacre bordés de perles) s'épanouit,
puis la carte « Save the Date » s'élève dans une pluie d'éclats avant l'invitation.

Pages : invitation, compte à rebours & programme, lieu, code couleur, mot des mariés, RSVP (message vocal). عربي / FR, musique.

## Lancer

```bash
npm install
npm run dev
```

## Personnaliser

Tout est dans **`src/config.js`** : prénoms, date, lieu, programme, couleurs, mot des mariés, langue de départ.

- Photo du lieu : `public/lieu.jpg` puis `image: '/lieu.jpg'`
- Musique : `public/musique.mp3`
- Réponses RSVP : `rsvpEndpoint`
